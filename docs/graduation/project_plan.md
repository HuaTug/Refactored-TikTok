# 毕业设计项目计划（TikTok 类 App 后端）

## 一、范围（Scope）
- 核心功能：注册登录、视频流、视频发布（含分片上传与合并）、点赞/评论、关注关系。
- 增强功能（可选）：消息、搜索/推荐、内容审核钩子、告警。
- 非功能性：
  - 性能：p95 延迟 < 80ms（缓存命中），>3k RPS 单机网关；
  - 一致性：最终一致；幂等消费；
  - 可观测：日志、指标、链路追踪齐全；
  - 可运维：Docker Compose 一键启动，健康检查。

## 二、架构与模块
- API Gateway（Hertz）：认证、路由、限流、统一返回。
- 微服务（Kitex）：User、Video、Interaction、Relation（Message 可选）。
- 存储：MySQL（分库分表）、Redis（缓存/分布式锁/布隆）、MinIO（对象存储）。
- 中间件：RabbitMQ（事件）、etcd（注册发现）、Jaeger（追踪）、ES（搜索/日志）。

## 三、工作分解（WBS）
1. 启动与基线：拉起基础设施；跑通最小用户注册/登录与视频流（Smoke）。
2. 上传链路：完善分片上传与合并；直传策略与签名；转码流水线（可异步）。
3. 互动链路：点赞/评论写路径事件化；计数校正；防重与重试。
4. 关系链路：关注/取关；Feed 聚合策略（简单时间线/关注流）。
5. 可观测性：打通日志、指标、追踪；错误预算与 SLO 设定。
6. 性能优化：缓存策略、连接池、限流熔断；热点与大 key 治理。
7. 评测与对比：压测、故障注入、方案对比；撰写报告。
8. 论文撰写：结构、图表、实验复现、相关工作。

## 四、风险与缓解
- 依赖多中间件 → Docker Compose 与 Mock 替身、文档化启动；
- 一致性复杂 → 明确最终一致与校正任务、Outbox 或事务消息；
- 性能不达标 → 预留容量与降级方案，优先优化读路径。

## 五、交付物
- 可运行代码与 Compose 编排、初始化脚本；
- 文档集合（API/事件驱动/评测/运维）；
- 压测报告与复现实验脚本（可选 k6/vegeta）；
- 论文初稿与终稿。
