# 毕业设计选题与开题建议

面向现有代码库（CloudWeGo: Hertz + Kitex，事件驱动，分布式缓存与对象存储），建议如下 5 个选题方向，均具备工程深度与研究性：

## 备选题目（含创新点）
1) 基于事件驱动架构的短视频平台设计与实现（CloudWeGo 实践）
   - 创新点：Outbox/事务消息保障最终一致性；热点计数的分片聚合；端到端链路追踪与异常画像。
2) 面向短视频业务的微服务性能优化与一致性研究
   - 创新点：读写分离 + 多级缓存 + 限流熔断的协同优化；p95/p99 延迟下降与可用性提升方法论。
3) 分片上传与边缘计算加速在短视频平台中的应用
   - 创新点：断点续传 + 服务器端分片合并；并行上传/转码流水线优化；MinIO 直传与回源策略。
4) 基于 Redis 与 MQ 的高并发互动系统（点赞/评论）设计与实现
   - 创新点：计数一致性策略、幂等消费、冷热分层；写扩散场景的削峰填谷策略。
5) 基于 CloudWeGo 的关系服务与社交图构建
   - 创新点：关注/粉丝拓扑优化；分页与推荐加速；一致性与可扩展性的平衡。

## 推荐题目（可直接采用）
- 题目：基于事件驱动架构的短视频平台设计与实现——以 CloudWeGo 为例
- 研究问题：
  1. 在高并发下如何兼顾用户体验（低延迟）与数据最终一致性？
  2. 缓存、MQ、数据库三者如何协同以保障幂等与故障自愈？
  3. 哪些性能优化手段最有效地降低 p95/p99 延迟？
- 预期贡献：
  - 提出一套“缓存优先 + 事务消息 + 分片计数”的工程实践方案；
  - 在真实系统中给出可复现的性能提升数据与故障演练结果；
  - 形成可复用的 CloudWeGo 微服务最佳实践文档与脚本。

## 可行性分析
- 代码与基础设施已具备：Hertz/Kitex、Redis、MySQL、MinIO、RabbitMQ、Jaeger、etcd、Elasticsearch。
- 主要工作聚焦在：完善文档与评测、补齐关键用例、增加观测与实验。

- 工程：可运行的多服务系统（Docker Compose），关键路径具备压测报告。
- 文档：API、事件驱动机制、部署与运维说明、评测报告。
- 论文：完整结构（见 paper_outline.md），包含图表、数据分析与对比。
