# 里程碑与时间安排（12 周样例）

- 第 1-2 周：环境搭建与基线跑通（用户/Feed），撰写开题报告
- 第 3-4 周：分片上传/合并与视频发布链路完善，最小转码流水线
- 第 5-6 周：互动链路事件化（点赞/评论），幂等/重试/DLQ 完成
- 第 7 周：关系链路与关注流，缓存策略与热点治理
- 第 8 周：可观测性完善（日志/指标/追踪），风控与限流熔断
- 第 9-10 周：性能优化与压测，故障注入与恢复演练
- 第 11 周：撰写论文初稿，图表与对比实验完成
- 第 12 周：论文定稿与答辩材料准备（Demo、海报、演示脚本）

可根据校历与个人节奏调整，每阶段以“可运行 + 可验证”为验收标准。
