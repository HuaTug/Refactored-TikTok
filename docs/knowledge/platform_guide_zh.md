# 小知短视频平台 - 用户使用指南

## 平台简介

小知（ZhiShi）是一个专注于知识分享和创意内容的短视频平台。用户可以在平台上上传、浏览、搜索和互动短视频内容，涵盖多个分类。平台配备了AI智能助手"小知"，帮助用户导航平台、发现内容和获取创作建议。

### 核心功能
- 视频上传与分享（标准视频、图片、全景/360°内容）
- 智能视频搜索，支持关键词、标签和分类筛选
- 热门话题和热点内容发现
- 社交互动：点赞、评论、关注和分享
- 个性化内容推荐
- AI智能助手提供平台使用指导和内容策略
- 多格式内容支持：MP4、MOV、AVI视频；JPEG、PNG、GIF图片
- 用户主页自定义：头像、简介和内容展示

## 用户注册与登录

### 如何注册账号
1. 打开小知APP或访问小知网页版平台
2. 在登录页面点击"注册"按钮
3. 输入您的邮箱地址或手机号码
4. 创建一个强密码（至少8位，包含字母和数字）
5. 完成验证流程（邮箱验证码或短信验证码）
6. 设置您的个人资料：选择用户名、上传头像、填写简介
7. 注册完成，开始探索小知平台！

### 注册常见问题

#### 注册时收不到验证码怎么办？
1. 检查手机号或邮箱地址是否输入正确
2. 查看短信是否被拦截或邮件是否在垃圾箱中
3. 等待1-2分钟后点击"重新发送验证码"
4. 如果多次尝试仍无法收到，请联系客服

#### 注册时提示"该手机号已注册"？
- 说明您之前已经用这个手机号注册过账号
- 请直接使用登录功能，输入手机号和密码登录
- 如果忘记密码，可以使用"忘记密码"功能重置

#### 注册对年龄有要求吗？
- 用户需年满13周岁方可注册使用平台
- 未满18周岁的用户将启用青少年模式

### 如何登录
1. 打开小知APP或网页版平台
2. 输入您注册时使用的邮箱/手机号和密码
3. 点击"登录"按钮
4. 如果开启了两步验证（2FA），需要输入验证码

### 忘记密码怎么办
1. 在登录页面点击"忘记密码"
2. 输入您注册时使用的邮箱或手机号
3. 您将收到重置链接或验证码
4. 设置新密码并确认

### 如何修改密码
1. 进入"设置" > "账号与安全"
2. 点击"修改密码"
3. 输入当前密码
4. 输入新密码并确认
5. 点击"保存"完成修改

## 视频上传

### 如何上传视频
1. 点击底部导航栏的"+"按钮
2. 从相册选择视频或直接录制新视频
3. 添加标题（建议不超过100个字符）
4. 填写详细的视频描述，帮助其他用户发现你的内容
5. 添加相关标签/话题标签（如 #编程 #教程 #科技）
6. 选择视频分类（如教育、娱乐、科技、生活等）
7. 选择可见范围：公开、私密或仅好友可见
8. 点击"发布"上传视频

### 支持的文件格式
- **视频格式**：MP4（推荐）、MOV、AVI、WebM
- **图片格式**：JPEG、PNG、GIF（用于图片动态）
- **全景/360°**：带360°元数据的MP4
- **文件大小限制**：普通用户最大500MB，高级用户最大2GB
- **推荐分辨率**：1080p（1920x1080）或更高
- **推荐画面比例**：9:16（竖屏），适合手机观看

### 上传技巧
- 使用良好的光线和稳定的画面，提升视频质量
- 视频时长建议在15秒到3分钟之间，获得最佳观看效果
- 添加字幕/说明文字，提高内容可访问性
- 使用吸引眼球的封面图来吸引观众

## 视频搜索

### 基本搜索
- 使用首页顶部的搜索栏
- 输入与内容相关的关键词
- 按回车或点击搜索图标查看结果

### 高级搜索功能
- **关键词搜索**：通过标题、描述或标签搜索视频
- **话题搜索**：输入#加话题名称（如 #美食制作）
- **用户搜索**：输入@加用户名搜索创作者
- **分类筛选**：按内容分类筛选结果（教育、娱乐、科技等）
- **时间范围筛选**：查找特定时间段的内容
- **热度排序**：按观看量、点赞数或最新上传排序

### 搜索技巧
- 使用具体的关键词获得更好的搜索结果
- 组合多个搜索词获得更精确的结果
- 使用引号进行精确短语匹配
- 查看热门话题标签发现热门内容

## 热门话题与趋势

### 热门机制说明
- "热门"板块展示当前最受欢迎的内容
- 热度得分基于加权公式计算：
  - 观看量：每次1分
  - 点赞：每次3分
  - 评论：每次5分
  - 分享：每次8分
  - 时间衰减：较近的互动权重更高
- 热门视频每小时更新一次
- 可选择不同时间窗口：1小时、6小时、24小时、7天

### 如何浏览热门内容
- 点击首页的"热门"标签页
- 按分类浏览热门话题
- 查看"急速上升"内容，发现正在快速增长的视频
- 查看"每周精选"板块，获取编辑推荐内容

## 社交互动

### 点赞
- 点击任何视频的爱心图标即可点赞
- 在观看视频时双击屏幕可快速点赞
- 在个人主页的"点赞"标签中查看所有点赞过的视频
- 点赞默认公开，可在设置中设为私密

### 评论
- 点击视频下方的评论图标查看或添加评论
- 填写评论内容后点击"发送"
- 点击"回复"可回复其他用户的评论
- 在评论中使用@用户名提及其他用户
- 评论支持表情和文字格式
- 可以在自己的视频下置顶评论
- 通过"..."菜单举报不当评论

### 关注与粉丝
- 点击任何用户主页上的"关注"按钮即可关注
- 在个人主页查看关注列表和粉丝列表
- 为特定创作者开启"通知"，收到他们发布新内容的提醒
- 可以拉黑用户，阻止他们查看您的内容或联系您

### 分享
- 点击分享图标分享视频
- 分享选项：复制链接、分享到其他APP、发送给平台好友
- 分享次数会计入视频的热度分数

   - **链接**：添加网站或社交媒体链接
   - **隐私设置**：控制谁可以查看您的内容和与您互动

## 常见问题

### 如何获得更多视频播放量？
1. **使用相关热门标签** - 研究所在分类的热门标签
2. **在高峰时段发布** - 最佳时间：12:00-13:00（午间）、18:00-20:00（晚间高峰）、周末10:00-12:00
3. **制作吸引人的封面和标题** - 第一印象很重要，使用清晰有吸引力的标题
4. **与观众互动** - 回复评论、提出问题、发起投票
5. **与其他创作者合作** - 互相推广有助于触达新观众
6. **保持稳定的更新频率** - 定期上传让观众保持关注
7. **善用热门音乐和形式** - 参与热门趋势和挑战
8. **优化视频时长** - 大多数分类中30-60秒的视频表现最佳

### 如何举报不当内容？
1. 点击视频上的"..."（更多选项）按钮
2. 选择"举报"
3. 选择举报原因：
   - 垃圾信息或误导性内容
   - 骚扰或欺凌行为
   - 仇恨言论或歧视
   - 暴力或血腥内容
   - 色情或露骨内容
   - 侵犯版权
   - 虚假信息
   - 其他
4. 必要时提供额外说明
5. 提交举报
6. 审核团队将在24小时内处理举报

### 账号安全建议
- 在"设置" > "安全" 中启用两步验证（2FA）
- 使用强密码且唯一密码（混合字母、数字、特殊字符）
- 不要将登录信息分享给任何人
- 定期在"设置" > "安全" > "活跃会话"中检查登录设备
- 退出不再使用的设备
- 警惕钓鱼链接和可疑消息
- 定期更换密码（建议至少每6个月一次）

### 如何注销/删除账号？
1. 进入"设置" > "账号" > "注销账号"
2. 阅读账号注销说明
3. 输入密码确认
4. 账号将进入30天冻结期（期间可以恢复）
5. 30天后所有数据将被永久删除

### 如何管理隐私设置？
1. 进入"设置" > "隐私"
2. 可用的隐私选项：
   - **账号可见性**：公开账号或私密账号
   - **谁可以评论**：所有人、仅粉丝或关闭评论
   - **谁可以私信**：所有人、仅粉丝或关闭私信
   - **谁可以看到我的点赞**：所有人、仅自己
   - **位置分享**：启用或关闭视频中的位置标签
   - **下载权限**：允许或禁止他人下载您的视频

### 支持上传哪些文件格式？
- **视频**：MP4（H.264/H.265）、MOV、AVI、WebM
- **图片**：JPEG、PNG、GIF（动图）、WebP
- **音频**：视频文件内支持（AAC、MP3）
- **文件大小限制**：普通用户500MB、高级用户2GB
- **时长限制**：普通用户最长10分钟、高级用户最长30分钟

## 内容推荐机制

### 推荐算法说明
平台使用多种算法组合推荐内容：
1. **协同过滤**：基于相似用户的偏好推荐
2. **内容推荐**：基于您的观看历史和兴趣偏好
3. **热门信号**：热门内容在推荐中获得加权
4. **创作者多样性**：系统确保您看到来自不同创作者的内容
5. **新鲜度**：新发布的内容获得临时推荐加权

### 如何优化推荐内容
- 对喜欢的内容点赞和互动
- 关注您感兴趣的创作者
- 对不感兴趣的内容使用"不感兴趣"选项
- 探索不同分类，拓宽推荐范围

## 社区规范

### 内容标准
- 所有内容必须遵守相关法律法规
- 禁止骚扰、仇恨言论或歧视行为
- 禁止暴力、血腥或令人不适的内容
- 禁止色情或露骨内容
- 禁止垃圾信息、诈骗或误导性内容
- 禁止侵犯版权 - 仅上传您拥有或有权使用的内容
- 禁止推广危险活动或物品

### 违规处理
- 违反规范的内容将被删除
- 多次违规可能导致临时或永久封禁账号
- 用户可以在7天内对内容删除决定提出申诉
- 平台AI审核系统会标记可能违规的内容交由人工审核

## 平台使用小技巧

### 观众技巧
- 上下滑动浏览视频流
- 长按视频可保存到收藏夹
- 使用"收藏"功能创建视频合集
- 在设置中启用"自动播放"实现连续观看

### 创作者技巧
- 研究数据分析面板，了解哪些内容表现最佳
- 发布后1小时内积极回复评论，获得最大曝光
- 使用"定时发布"功能在最佳时间发布内容
- 尝试不同内容形式，找到最适合您的风格
- 使用内置视频编辑器添加转场、滤镜和文字覆盖

### 网页版快捷键
- `空格`：播放/暂停视频
- `↑/↓`：上一个/下一个视频
- `L`：点赞视频
- `C`：打开评论
- `M`：静音/取消静音
- `F`：全屏切换
