# 小知短视频平台 - 技术常见问题

## 系统要求

### 手机APP
- **iOS**：iOS 14.0 及以上版本，推荐 iPhone 8 或更新机型
- **Android**：Android 8.0 及以上版本，推荐至少 3GB 运行内存
- **存储空间**：APP本体至少需要200MB空闲空间，另需为下载内容预留额外空间

### 网页版
- **浏览器**：Chrome 90+、Firefox 88+、Safari 14+、Edge 90+
- **屏幕分辨率**：最低 1280x720，推荐 1920x1080
- **网速要求**：流畅播放视频最低需要 5 Mbps，推荐 10 Mbps

## 常见技术问题

### 视频无法播放
1. 检查网络连接速度
2. 尝试刷新页面或重启APP
3. 清除APP缓存（设置 > 存储 > 清除缓存）
4. 将APP更新到最新版本
5. 如果问题持续存在，该视频可能已被创作者删除

### APP频繁闪退
1. 更新到最新版本的APP
2. 清除APP缓存和数据
3. 重启设备
4. 确认设备满足最低系统要求
5. 如果问题仍然存在，卸载后重新安装APP

### 上传速度太慢
1. 检查网络上传速度（建议至少 5 Mbps）
2. 上传前压缩视频（使用 H.264 编码获得最佳兼容性）
3. 尝试在非高峰时段上传
4. 关闭其他占用带宽的应用
5. 尝试使用WiFi连接代替移动数据

### 上传后视频画质变差
- 以最高可用分辨率上传（1080p 或更高）
- 使用推荐编码格式：H.264（MP4 容器）
- 避免上传前多次重复压缩
- 平台会将视频重新编码为不同画质等级，这属于正常现象
- 高清画质处理最多需要1小时才能完成

### 搜索没有结果
1. 检查搜索关键词是否有拼写错误
2. 尝试使用不同的关键词或更宽泛的搜索词
3. 使用话题标签搜索（#标签）获得更精确的结果
4. 按分类筛选缩小搜索范围
5. 搜索索引每隔几分钟更新一次，非常新的内容可能暂时搜索不到

## API 接口信息

### 平台API
- 小知平台为开发者提供 RESTful API
- API根路径：/v1/
- 认证方式：基于 JWT（JSON Web Token）
- 频率限制：普通用户每分钟100次请求

### 可用 API 接口
- **视频操作**：搜索、上传、播放、管理视频
- **用户操作**：注册、登录、个人资料管理
- **互动操作**：点赞、评论、关注、分享
- **AI 操作**：与AI助手对话、知识库查询

## 数据与隐私

### 数据收集
- 我们收集使用数据以改善平台体验
- 视频观看记录用于内容推荐
- 未经用户明确同意，不会与第三方共享个人数据

### 数据导出
1. 进入"设置" > "隐私" > "下载我的数据"
2. 提交数据导出请求（48小时内处理完成）
3. 处理完成后通过邮箱收到下载链接
4. 导出数据包含：个人资料、视频、评论、点赞和账号活动记录

### 数据删除
- 个人视频可随时删除
- 评论可由评论者或视频作者删除
- 支持完整账号注销（详见账号常见问题部分）
- 提交账号注销请求后30天，所有数据将被永久删除

## 性能优化

### 流畅播放建议
- 在"设置" > "视频"中启用"自动画质"，让APP自动选择最佳画质
- 关闭后台应用以释放内存
- 使用WiFi代替移动数据以获得稳定的网速
- 启用"预加载视频"功能缓冲即将播放的内容

### 高效上传建议
- 推荐的视频上传设置：
  - 编码格式：H.264
  - 容器格式：MP4
  - 分辨率：1080x1920（竖屏）
  - 帧率：30fps
  - 码率：5-10 Mbps
  - 音频：AAC，128kbps 或更高

## 无障碍功能

### 可用功能
- 字幕/说明文字：支持自动生成和创作者提供的字幕
- 屏幕阅读器兼容导航
- "设置" > "无障碍"中的高对比度模式
- 可调节播放速度（0.5x、1x、1.5x、2x）
- 评论和描述的文字大小调节
- 为敏感用户提供减少动画选项

### 如何启用无障碍功能
1. 进入"设置" > "无障碍"
2. 开启/关闭所需功能
3. 大部分功能立即生效，无需重启APP
